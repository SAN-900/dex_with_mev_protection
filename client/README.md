Aroha DEX Frontend

AI-powered Solana DEX frontend with MEV protection, smart swap analysis, and real-time risk monitoring.

Features
Solana wallet integration
Jupiter-powered token swaps
AI risk analysis before swaps
MEV protection system
Auto-Protect trading mode
Real-time confidence scoring
Route complexity analysis
Modern responsive UI
Dark / Light mode support
Tech Stack
React
TypeScript
Vite
TailwindCSS
Solana Wallet Adapter
Jupiter API
shadcn/ui
Setup

Clone the repository:

git clone https://github.com/SAN-900/dex_with_mev_protection
cd client

Install dependencies:

npm install

Create environment file:

VITE_BACKEND_URL=
VITE_PROXY_URL=

Start development server:

npm run dev
Build
npm run build
Deployment

Frontend is deployed on Vercel.
