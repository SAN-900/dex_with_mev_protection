# Jupiter Proxy Server

Proxy server for interacting securely with Jupiter APIs.

---

# Features

- Fetch swap quotes
- Generate swap transactions
- Fetch token lists
- Handle Jupiter API requests

---

# Tech Stack

- Node.js
- Express
- TypeScript

---

# API Endpoints

```text
/jupiter/quote
/jupiter/swap
/jupiter/tokens
````

---

# Run Locally

```bash
npm install
npm run dev
```

---

# Production Build

```bash
npm run build
npm start
```

---

# Responsibilities

* Jupiter API proxying
* Swap transaction generation
* Quote handling
* Token data serving
